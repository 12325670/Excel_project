📊 Google Fit Data Analysis – README
📁 Project Overview
This project analyzes personal health and activity data collected via Google Fit, using Microsoft Excel for data cleaning, transformation, and visualization. The goal is to derive insights related to physical activity, sleep, heart rate, and daily trends.

📄 Data Source
Source: Google Fit
Key Data Types:

Steps

Distance walked/run

Calories burned

Heart rate

Sleep segments

Move minutes

📌 Objective
Identify daily, weekly, and monthly activity patterns

Track progress towards fitness goals

Visualize trends in sleep, heart rate, and physical activity

Provide actionable insights for healthier lifestyle habits

🛠️ Tools Used
Microsoft Excel

Pivot Tables

Charts (line, bar, scatter, etc.)

Conditional Formatting

Lookup functions (VLOOKUP/XLOOKUP)

Date & Time functions

📈 Key Insights (Example)
Average daily step count over time

Correlation between sleep duration and step activity

Peak activity hours during the day

Trends in resting heart rate over months

🧹 Data Cleaning & Processing
Removed duplicate entries

Parsed timestamps into date and time formats

Converted distance units (e.g., meters to kilometers)

Aggregated data on a daily/weekly/monthly basis
